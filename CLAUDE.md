# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Imobia: an AI agent on WhatsApp that answers a solo real-estate broker's clients automatically, plus a kanban showing each client's stage in a property sale (any property type). The repo was restarted from scratch on 2026-10-26; only the app skeleton exists so far. The local folder is still named `loteAI`, but the old loteAI CRM is gone; don't reference or recreate it.

## Stack

- **TanStack Start** for the app, with **TanStack Query** for reads (route `loader` calls `queryClient.ensureQueryData`, components read with `useSuspenseQuery`), and **TanStack Form** for forms.
- Writes go through **server functions** (`createServerFn`) called from `useMutation`.
- **MUI 9** with a custom theme built from zero.
- **Bun** as runtime, package manager and toolchain.

Still open, to be decided **after** the domain is modeled: database, auth, WhatsApp provider. Don't pick or install any of them before that. Deploy will target an existing OCI VPS later; there's no deploy workflow yet.

## Commands

```sh
bun install
bun --bun run dev                # dev server on :3000
bun run build
bun run typecheck                # tsc --noEmit
bun fmt                          # format (config in bunfig.toml: no semicolons, single quotes)
bun fmt --check
bun lint                         # oxlint, config in .oxlintrc.json
bun test                         # all tests
bun test path/to/file.test.ts    # one file
bun test -t "test name"          # tests matching a name
```

## Layout

- `src/router.tsx` creates one `QueryClient` per router (that is, per SSR request) and passes it as router context; `setupRouterSsrQueryIntegration` handles dehydration/hydration. Routes reach it via `context.queryClient` in loaders.
- `src/routes/__root.tsx` is the HTML shell: Emotion `CacheProvider` → MUI `ThemeProvider` → `CssBaseline`, plus TanStack devtools.
- `src/theme/theme.ts` holds the MUI theme (`cssVariables: true`). It is intentionally near-empty; the theme is being designed from zero.
- `src/routeTree.gen.ts` is generated by the router plugin on dev/build (or `bunx tsr generate`); never edit it by hand.
- `vite.config.ts` sets `ssr.noExternal: ['@mui/*']` so MUI is bundled for SSR.
